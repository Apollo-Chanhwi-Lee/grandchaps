# 내 Mac에 설치하기 (Apple Silicon)

설치 파일 하나를 내려받아 더블클릭하면 됩니다. git이나 개발 환경을 설치할 필요가 없습니다. 곡 만들기 계산은 **모두 내 Mac에서** 일어나고, 내 Mac에서만 열리는 주소(127.0.0.1)로 브라우저에서 씁니다.

## 흐름
1. **받기:** GitHub 저장소의 Releases 페이지에서 `Instmate-Mac-Installer.command` 하나를 내려받습니다. (Release가 공개되기 전에는 이 파일이 없습니다. 공개 준비 중입니다.)
2. **실행:** 파일을 더블클릭합니다. 서명되지 않은 파일이라 "확인되지 않은 개발자" 경고가 나옵니다(앱 창이 아니라 브라우저로 쓰는 방식이어도 같습니다). 먼저 파일을 **우클릭하고 열기**를 눌러 보세요. 그래도 막히면 **시스템 설정 > 개인정보 보호 및 보안**에서 이 파일 옆의 **"그래도 열기"**를 누릅니다(최근 macOS에서는 우클릭이 안 먹힐 수 있습니다). 경고 없이 하려면 터미널에서 `cd ~/Downloads && zsh Instmate-Mac-Installer.command`를 실행하세요(터미널에서 실행하면 보통 이 경고가 나오지 않습니다).
3. **처음 실행:** 설치 파일이 `~/instmate_app`에 앱을 풀고, 필요한 프로그램을 설치한 뒤(몇 분, 인터넷 필요), 내 Mac에서 서버를 켜고 브라우저에 작곡메이트를 자동으로 엽니다. 터미널 창을 닫으면 앱도 꺼집니다.
4. **노래 모델 받기:** 앱 첫 화면의 "처음 한 번: 노래 모델 받기" 카드에서 받습니다. **크기 약 4.5GB, 비상업(CC BY-NC 4.0) 조건**에 동의하는 체크를 해야 받기 버튼이 눌립니다. 받는 것은 모델 파일과 실행 코드(.py 3개)이고, 공개 저장소의 **고정된 한 버전**(`fe0a905`)만 받으며 받은 뒤 크기와 검증값을 확인합니다. 진행률이 보이고, 인터넷이 끊기면 멈추며 다시 누르면 이어서 받습니다. 카드는 접힌 한 줄이라 아래 입력창이 가려지지 않습니다. 받지 않아도 악보와 MIDI 만들기는 됩니다. 노래(YuE2)만 빠집니다.
4-1. **설치가 중간에 멈췄다면:** 같은 파일을 다시 열면 멈춘 곳(패키지 설치)부터 이어서 합니다. 완료 표시는 모든 패키지가 설치된 뒤에만 남습니다.
5. **업데이트:** 새 설치 파일을 같은 방법으로 실행하면 앱 코드만 바뀌고, 설치된 프로그램과 받은 모델, 내 곡은 그대로입니다.
6. **지우기:** `~/instmate_app` 폴더를 지우면 됩니다.

## 지원하는 환경 (실제로 지원하는 것만)
- **macOS, Apple Silicon(M1 이상)만.** Windows, Intel Mac, Linux는 지원하지 않습니다(노래 모델과 작곡 모델이 MLX 전용).
- **미리 있어야 하는 것:** `uv`(`brew install uv`) **또는** Python 3.11 이상. `uv`만 있어도 됩니다(첫 실행이 `uv`로 Python을 준비합니다). 설치 파일이 Python을 따로 넣어 주지는 않습니다. 둘 다 없으면 첫 실행이 정확히 무엇을 설치하라고 안내하고 멈춥니다.
- 설치 폴더 이름은 영문·숫자·`.`·`_`·`-`만 가능합니다(기본 `~/instmate_app`). `INSTMATE_HOME`으로 바꿀 수 있습니다.
- 저장 공간과 메모리는 측정한 값이 아닙니다. 프로그램 수 GB, 모델 약 4.5GB가 필요하고, YuE2로 노래를 만들 때는 메모리를 많이 씁니다(개발 Mac에서 약 18GB까지 확인). 메모리가 적은 Mac에서는 노래 만들기가 안 될 수 있습니다.
- **기본 설치에서 안 되는 것(화면이 미리 알려 줍니다):** PDF 악보 읽기(poppler와 homr 필요, MIDI·MusicXML은 바로 됩니다), 기타·베이스·건반·드럼을 빼고 연습(Demucs 필요, 보컬 연습은 됩니다). 이 도구들은 설치 파일에 들어 있지 않습니다.
- 선택: 악보를 소리로 듣는 도구는 `brew install fluid-synth ffmpeg`. 대화 모델은 `brew install ollama && ollama serve && ollama pull qwen3:14b`, 또는 화면의 "내 Gemini 키 쓰기"(키는 이 브라우저에만 저장).

## 이 앱에 들어 있지 않은 것
- 모델 가중치 전부, 사운드폰트, 학습 데이터, 참고 음원, 사용자 곡, 키와 코드.
- 리드시트 모델은 비영리 조건의 데이터로 학습해서 나눠 드리지 않습니다. 없어도 올린 멜로디를 바탕으로 규칙으로 곡을 만듭니다.

## ZIP으로 받았다면
ZIP을 영문 폴더에 풀고 `start_mac.command`를 더블클릭하거나 터미널에서 `zsh start_mac.command`를 실행하세요. 같은 경고가 나올 수 있고 해결 방법도 같습니다. 이후는 위 3~4번과 같습니다.

## 안 될 때
- "폴더 이름에 한글…": 영문 이름 폴더로 옮기거나 `INSTMATE_HOME`을 바꾸세요.
- "포트 8000을 쓰고 있어요": 앱이 이미 켜져 있는지 확인하세요. 다른 포트는 `INSTMATE_PORT=8001`.
- 멈춘 줄의 오류 문장을 그대로 알려 주세요.

## 알려진 한계
- 이 흐름은 **깨끗한 새 Mac에서 처음부터 끝까지 실행해 확인하지 않았습니다.** 확인한 것: 설치 파일의 풀기·검증·거부 동작, 앱의 로컬 서버 시작과 브라우저 열기 호출(열기 명령은 기록만 하는 대체물로), 모델 받기 화면의 동작(가짜 다운로더로). 실제 4.5GB 모델 받기와 패키지 설치는 실행하지 않았습니다.
- 서명과 공증을 하지 않았습니다. 경고가 나오는 것이 정상이고, 위 방법 중 하나로 한 번만 허용하면 됩니다. 경고가 나오는 정확한 모양과 해결 방법은 macOS 버전마다 다를 수 있어 이 Mac(개발 환경)의 모든 버전에서 확인하지 못했습니다.
